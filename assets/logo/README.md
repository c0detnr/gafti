# GAFTİ renk paleti

| Renk | Hex | Kullanım |
|---|---|---|
| Ladin yeşili | `#173629` | Harf konturu, ikon zemini ve ilerleme çubuğunun boş kısmı |
| Filiz | `#C8EB76` | Harflerin ışık alan üst kenarı |
| Çay yeşili | `#9BDB61` | Harf yüzeyi ve seçim kenarı |
| Çayır | `#67BB63` | Harflerin alt tonu |
| Lamba turuncusu | `#F49B50` | İ noktası, harflerin alt gölgesi, klavye odağı ve ilerleme |
| Kaymak | `#FFF0CC` | Metin, harf parlamaları ve dış kontur |
| Ceviz | `#392D26` | Panel zemini |
| Orman | `#233E31` | PanelContainer zemini |
| Yosun | `#315A40` | Düğme yüzeyi |
| Islak taş | `#53635B` | Devre dışı denetimlerin kenarı |

Yazı logosu şeffaf zeminlidir. İkon aynı G harfini ve turuncu yaprağı yuvarlatılmış ladin yeşili bir karede birleştirir.
